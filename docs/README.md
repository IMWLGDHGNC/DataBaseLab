## 文件职责与历史记录

- `week5/` 与 `week6/` 同时保存该周说明和已有图源，脚本继续使用这些固定位置；新增同周材料放回对应目录。
- `reports/` 放阶段公开报告，`submission/` 放清单、分工与AI索引；完整AI记录仅维护根目录 `ai_log.md`。
- `guides/` 放环境及公开材料规则。署名报告、私下提交包、凭据和本机产物保存在仓库外或被忽略的目录。
- `verification/` 是第三周脚本仍会写入的历史路径；`result/` 中现有日志和截图同样保留原路径，不为归档改变已有证据位置。

第7–9周说明统一使用 `week7-9/`。执行脚本、SQL授权及历史结果中的 `Week7` / `week7` 沿用既有名称，均对应第7–9周合并任务；这些路径及原有PASS标记用于保持复现和历史证据兼容。
