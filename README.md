## 当前内容

第一周业务分析草稿包含经营场景、角色职责、核心数据对象、Mermaid 业务流程与订单状态图、数据边界、初步业务规则及后续阶段衔接。第二周已形成覆盖商品、采购、批次库存、销售、模拟支付和积分的 15 表关系模式草案，列出字段域、码和互相关联的虚构样例元组。设计与业务假设仍待组员人工复核，尚未建库或运行 SQL。

本周按课程要求不写 SQL、不建表；后续使用 SQL Server 逐步实现。Mermaid 图可在 GitHub 文档页中查看。
