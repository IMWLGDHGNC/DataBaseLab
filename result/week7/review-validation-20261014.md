## 六项修复对应

| review 问题 | 修复与验证 |
| --- | --- |
| 下单与出库锁顺序相反，可能 SQL 1205 死锁 | 所有业务写事务在锁业务行之前获取共同、事务持有的 `sp_getapplock`；模拟原交错时序后两请求分别 201/200。提交或回滚自动释放。小规模课程应用选择串行写入，可能降低写吞吐；十秒等待失败返回 409 TRANSACTION_CONFLICT。 |
| 手册直接测试命令导入 app 失败 | 测试入口加入仓库根目录；直接运行进入配置加载，完整测试执行通过。 |
| 增改明细总金额超过 DECIMAL(10,2) 返回服务不可用 | 创建、增、改、删明细统一核对总金额；两个溢出编辑返回 400 INVALID_INPUT，11 张受影响表摘要保持不变。 |
| INT 超界及 inf/nan 输入误报数据库失败/500 | 数量和阈值校验 SQL INT 范围并捕获转换溢出，盘点同时核对最终余额；非法值返回 400。数据库数值/长度超限另统一归类输入错误。 |
| 新商品没有 Web 入库流程 | 管理员建立并审批单商品采购，店员按批准数量整单验收，原子写入批次、入库流水及采购状态；到期日期非法返回 400，重复收货返回 409。新商品可继续下单、支付和出库。 |
| 权限矩阵宣称管理员能创建/编辑/取消顾客订单 | 矩阵与服务、页面一致：这些操作及支付由顾客本人执行；管理员管理商品、采购、库存与出库。管理员下单实际返回 403。 |
